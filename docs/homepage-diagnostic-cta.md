# CTA de diagnóstico para la portada

## Bloque propuesto

**Título:** ¿No sabes por dónde empezar?

**Texto:** Identifica el problema que más tiempo te está quitando y descubre qué tipo de herramienta puede ayudarte.

**Botón:** Haz tu diagnóstico

**Destino:** `/diagnostico/`

## Reglas de implementación

- Colocarlo después de las cuatro categorías y antes del bloque de transparencia.
- Mantener un único CTA primario en el bloque.
- No prometer resultados ni presentar el diagnóstico como asesoramiento profesional.
- Conservar foco visible, contraste suficiente y área táctil cómoda.
- Medir el clic como `diagnostic_started`, sin datos personales.

## Validación

- La URL debe resolver a la página pública Diagnóstico.
- El botón debe funcionar con teclado y móvil.
- El bloque no debe ocultar la transparencia de afiliación.
