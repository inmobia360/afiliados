# Agentes del proyecto

Los agentes se organizan por responsabilidad y entregables. `@director` es la única instancia que integra cambios entre dominios. Cada especialista debe leer `AGENTS.md`, `docs/constitution.md` y la spec activa antes de actuar.

## Contrato de salida

```text
Resultado:
Requisitos cubiertos:
Archivos propuestos o modificados:
Supuestos:
Riesgos:
Validación ejecutada:
Bloqueos o decisión humana requerida:
```

Las definiciones detalladas de roles están en `docs/agent-architecture.md`.
