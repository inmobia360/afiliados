# Brújula Digital — Catálogo de herramientas

Plugin MVP para WordPress con CPT público `herramientas`, taxonomías `necesidad`, `perfil`, `nivel` y `tipo`, campos editoriales/internos y shortcode `[brujula_herramienta]`.

Instalar en `wp-content/plugins/`, activar en staging y crear una herramienta de prueba. No contiene productos ni enlaces afiliados reales. La política de afiliación debe validarse antes de publicar cada ficha.
