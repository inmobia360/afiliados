# Plantilla editorial de landing de producto

Esta plantilla se reutiliza para cada herramienta. No debe publicarse con marcadores sin revisar.

## 1. Encaje rápido

- Producto:
- Frase de utilidad:
- Para quién sí:
- Para quién no:
- Problema principal:
- Categoría:
- Nivel: inicial / intermedio / avanzado

## 2. Contexto del usuario

Explicar una situación concreta del día a día, sin prometer ingresos ni resultados garantizados.

## 3. Qué hace

Describir el funcionamiento con lenguaje sencillo y ejemplos aplicables al público de Brújula Digital.

## 4. Casos de uso

Incluir entre tres y cinco casos de uso verificables, evitando convertir prestaciones en promesas.

## 5. Ventajas y límites

Mostrar ventajas concretas y limitaciones relevantes. La landing no debe parecer un anuncio unilateral.

## 6. Coste y condiciones

- Plan o rango de precio:
- Moneda:
- Frecuencia:
- Fecha de revisión:
- Prueba o plan gratuito:
- Información pendiente:

Si el precio cambia por país, impuestos, usuarios o contratación, explicarlo y enlazar a la fuente oficial.

## 7. Alternativas

Comparar con una o dos opciones por criterio de encaje, no por comisión.

## 8. CTA y transparencia

CTA principal: `Comprobar [producto]`.

Texto de disclosure recomendado:

> Este botón contiene un enlace de afiliado. Si contratas el servicio, Brújula Digital podría recibir una comisión, sin coste adicional para ti.

El enlace debe llevar `rel="sponsored"` y solo activarse después de completar la ficha de cumplimiento.

## 9. Evidencia editorial

- Fuentes oficiales consultadas:
- Fecha de consulta:
- Claims permitidos:
- Claims descartados:
- Capturas, logos o vídeos autorizados:
- Revisión de políticas completada: sí / no

## 10. Estados de publicación

`borrador` → `investigación` → `revisión-afiliación` → `revisión-editorial` → `aprobado` → `publicado` → `retirado`.

Solo `aprobado` puede pasar a publicación y requiere revisión humana.
