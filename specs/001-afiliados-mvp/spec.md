# Spec 001 — MVP de AFILIADOS AI

## Objetivo

Ayudar a un profesional inmobiliario a identificar herramientas adecuadas para un punto de dolor y avanzar hacia una recomendación o ficha de producto con suficiente confianza para probarla.

## Usuarios

- Agente inmobiliario autónomo con poco tiempo y baja tolerancia a herramientas complejas.
- Pequeña inmobiliaria que quiere estandarizar captación, seguimiento, marketing y automatización.

## Historias

- Como agente, quiero elegir mi problema para no navegar un catálogo genérico.
- Como agencia, quiero comparar opciones por resultado, coste, dificultad e integración.
- Como visitante, quiero saber cuándo existe afiliación y qué datos se recopilan.

## Requisitos funcionales

- RF-1: Cuando un visitante seleccione un punto de dolor, el sistema debe mostrar soluciones categorizadas y explicar el resultado esperado.
- RF-2: Cuando se muestre una recomendación, debe incluir caso de uso inmobiliario, pros, límites, coste verificable o pendiente, esfuerzo y CTA.
- RF-3: Cuando exista enlace afiliado, debe mostrarse una divulgación visible antes o junto a la acción relevante.
- RF-4: El catálogo debe distinguir estado `verificado`, `pendiente` y `retirado`, con fuente y fecha para los datos verificables.
- RF-5: El sitio debe funcionar en móvil, teclado y lectores de pantalla en los recorridos principales.
- RF-6: La analítica debe medir pasos del embudo sin almacenar PII innecesaria.

## Fuera de alcance del MVP

Marketplace abierto, asesoramiento legal/financiero, checkout propio, confirmación automática de compatibilidad o resultados garantizados.

## Pendientes de clarificación

Nombre definitivo, primer segmento prioritario, categorías iniciales, fuentes de productos, plataforma técnica, proveedor de analítica y modelo de consentimiento.
