# Brújula Digital — sistema inicial de marca

## Posicionamiento

Brújula Digital orienta a profesionales independientes, empresarios y pequeñas empresas hacia herramientas digitales útiles para trabajar mejor, automatizar procesos y crecer con criterio.

## Paleta oficial inicial

| Token | HEX | Uso |
|---|---|---|
| `navy` | `#12355B` | Texto principal, navegación y fondos de confianza |
| `blue` | `#2563EB` | Acciones, enlaces y elementos interactivos |
| `turquoise` | `#14B8A6` | Automatización, progreso y estados positivos |
| `orange` | `#F97316` | Acentos, señales y llamadas de atención |
| `surface` | `#F7FAFC` | Fondos claros y superficies |

## Dirección visual

- Tecnología cercana, no futurismo frío.
- Mucho espacio en blanco y jerarquía clara.
- Azul marino para confianza; azul para acción; turquesa para progreso; naranja con moderación.
- El símbolo de brújula representa orientación, conexión y descubrimiento.
- La marca debe funcionar tanto en web como en futuras herramientas y app.

## Aplicaciones previstas

- Logotipo horizontal para cabecera y documentos.
- Símbolo para favicon, app, avatar y tarjetas compactas.
- Fondo claro para la experiencia principal.
- Fondo navy para bloques de contraste y landings de producto.
- CTA principal en azul; naranja reservado para señales secundarias.
